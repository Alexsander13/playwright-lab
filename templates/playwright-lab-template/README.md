# Playwright Lab starter

Минимальный проект для учебного курса Playwright Lab.

В Модуле 0 вы установите зависимости и браузер, настроите конфигурацию и напишете первый smoke-тест. Начните с `npm ci`, затем следуйте задачам курса.

Тестируемая система курса — Expand Testing Notes App и Notes API. Не добавляйте в Git пароли, токены или локальные `.env`-файлы.
