# Playwright Lab: Ground Truth

Этот документ — единственный источник утверждённых решений по продукту и порядку разработки. При расхождении с черновиками и старыми формулировками применять этот документ и исправлять конфликтующие документы.

## Продукт и репозиторий

- Название проекта: **Playwright Lab**.
- Репозиторий — единый монорепозиторий, в котором развиваются учебный контент и код веб-платформы.
- Платформа: Next.js App Router, TypeScript strict, Tailwind CSS, Supabase (PostgreSQL).
- Курс создаётся полноценно и последовательно, модуль за модулем, начиная с Модуля 0. Прототипов и усечённых версий нет.
- Курс: начата задача 0.1; к задаче 0.2 переходить только после её завершения.
- Веб-платформа: шаги 1–6 реализованы; Supabase-схема и GitHub OAuth проверены на production. Дашборд и урок доступны; первая запись учебного прогресса ожидает действия ученика.

## Учебная программа

- Модули 0–9 содержат 59 практических задач.
- Модуль 9 посвящён AI-ассистентам и кастомному репортёру с OpenRouter.
- Модуль 10 — Wrap-up & Celebration: финальный чек-лист готовности проекта для резюме и завершение курса. Формальной аттестации и дополнительных задач после Модуля 9 нет.
- Каждый урок оформляется по `COURSE_AUTHORING_GUIDELINES.md`; модули проходят строго по порядку.

## Проверка и прогресс

- CLI-проверка предоставляется командой `npm run verify` и развивается параллельно с учебными модулями.
- Проверка синхронизирует прогресс с Supabase. Секреты не встраивать в клиентский код и не добавлять в Git.

## План веб-платформы

Утверждённый рабочий план — раздел 7.1 `playwright-course-technical-plan.md`. Шаги 1–6 выполнены: схема Supabase и RLS применены; GitHub OAuth работает; защищённый дашборд, маршрут задачи 0.1, demo-команда и запись прогресса реализованы; production развёрнут на Vercel.

Прогресс хранить на уровне задания: выполнение задачи 0.1 не должно автоматически отмечать завершённым весь Модуль 0. Статус модуля рассчитывается из статусов его задач.

Техническая реализация задачи 0.1 готова. Урок предоставляет скачиваемый standalone-скрипт; пользовательский прогресс остаётся незавершённым, пока ученик не запустит демо и явно не отметит задачу выполненной.

Все пять уроков Модуля 0 (0.1–0.5) подготовлены в платформе. Публичный starter-template: https://github.com/Alexsander13/playwright-lab-template. Доступ к урокам не меняет прогресс: отметить следующую задачу можно только после завершения предыдущей.

Все шесть уроков Модуля 1 (1.1–1.6) также подготовлены без запуска тестов приложения. Они доступны в материалах, но отмечать их можно только после последовательного завершения Модуля 0.

Все восемь уроков Модуля 2 (2.1–2.8) подготовлены по исходной программе. Контент доступен без завершения предыдущих модулей, но отметить задачу 2.1 можно только после выполнения задач 0.1–0.5 и 1.1–1.6 по порядку.

## SUT и конфигурация окружения

- Единственная тестируемая система курса (SUT) — Expand Testing: Notes App и Notes API.
- Адреса централизуются в `src/config/env.ts`: `BASE_URL` для UI и `NOTES_API_URL` для Notes API. Другие адреса выводятся из этих значений; новые URL-переменные не вводить.
- В тестах не записывать домены напрямую. Секреты хранить в переменных окружения и исключать из Git.

## Безопасность AI-отчёта

В OpenRouter разрешено отправлять только текст ошибки, stack trace и минимальный фрагмент DOM, относящийся к упавшему локатору. До отправки исключать пароли, персональные данные, токены авторизации (включая `x-auth-token`) и чувствительные значения окружения. Не отправлять полный DOM или сетевые заголовки.
