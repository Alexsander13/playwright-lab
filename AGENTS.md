# AGENTS.md

## Обзор проекта

Это небольшой проект на TypeScript с ESM-модулем. Основная точка входа: `src/index.ts`.

## Команды разработки

- Установка зависимостей: `npm install`
- Запуск в режиме разработки: `npm run dev`
- Сборка проекта: `npm run build`
- Запуск собранного приложения: `npm start`

## Правила для AI-агентов

- Все пояснения, комментарии, ответы и описания должны быть на русском языке.
- Коммиты писать в формате Conventional Commits, например: `feat: add initial project config`, `fix: correct TypeScript build setup`, `docs: update project instructions`.
- Перед завершением задачи всегда проверять отсутствие синтаксических ошибок и неиспользуемых импортов.
- Предпочитать минимальные и точечные изменения без лишнего рефакторинга.
- Не создавать новые зависимости без необходимости.
- Сохранять структуру проекта простой и понятной; текущая схема: `src/` для исходников, корневые конфиги для TypeScript и сборки.

## Качество кода

- Перед завершением задачи запускать: `npm run build`
- Если в проекте появляются импорты, убедиться, что они действительно используются.
- Не оставлять отладочный код и временные комментарии.
- Следовать типобезопасному TypeScript-стилю и избегать неочевидных `any` без необходимости.

## Примечания

- В проекте пока нет тестового раннера; основной проверкой является успешная сборка.
- Если требуется добавить новые модули или файлы, придерживаться существующей простой структуры и именования.
